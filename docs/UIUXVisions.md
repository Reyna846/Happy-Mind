# Visual direction
Premium, quiet lavender: Lora editorial headings and companion copy; DM Sans controls. Rich plum is reserved for primary actions and the current navigation item. Secondary buttons use translucent glass with one light edge, restrained shadow and consistent round shapes. Selected technique chips keep dark text on pale glass. Keep body contrast and 44px minimum targets.

`src/controls.css` is the final control styling layer after layout/responsive styles. Refine shared roles there instead of adding unrelated button styles per feature. Listen is primary, Next is secondary, Stop is a labelled icon control. Focus is a distinct 2px plum outline with a soft white halo; never hide keyboard focus. Hover lift is subtle and disabled with reduced motion.

Avoid competing borders, tiny labels, heavy black focus boxes, deep embossed effects or multiple equal primary actions in one group. Mode controls scroll normally so they do not obscure subtitles on short phones. Bedtime keeps its dark palette and visible light focus treatment.

Talk uses a rounded thin-line speech mark with a flowing inner stroke; Chat uses the same silhouette with text lines. Home swipes use a short tapered ribbon with eased tracking and sparse light particles, retiring after release; disabled with Less movement/reduced motion.

Button depth: shallow top highlight, slightly darker lower edge and two soft outer shadow layers; pressed controls sink inward. Keep the bevel subtle and preserve focus outlines.
